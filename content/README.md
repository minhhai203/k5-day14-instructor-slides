# Nội dung deck

- `build_content.py`: HTML và speaker notes của từng slide. Chạy `python3 -I content/build_content.py` từ thư mục gốc để sinh `app/src/slides/content.json`.
- `icons.json`: SVG Lucide dùng trong slide.

## Nguồn sự thật

Repo lab [VinUni-AI20k/K5-L3-Day14-Deployment-Agent-Benchmark-Observability](https://github.com/VinUni-AI20k/K5-L3-Day14-Deployment-Agent-Benchmark-Observability), nhánh `main`:

- `README.md` mục “⚠️ Lưu ý khi làm bài (K5)”: các lệnh khác `CODE_LAB.md`.
- `CHECKPOINTS.md`: CP0–CP8, giờ, lệnh tự kiểm.
- `RUBRIC.md`: tối đa 120 điểm, đổi về thang 100; Part 3 (8) và Part 6 (60) chia theo bảng K5.
- `RULES.md`, `SUBMISSION.md`: luật, tên repo, cây nộp bài, hạn 23h59.
- `06-lab-complete/README.md`: tiêu chí script chấm.

Khi repo lab thay đổi, cập nhật `build_content.py` rồi chạy lại.
